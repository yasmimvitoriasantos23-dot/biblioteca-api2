Como começar

  1. Cadastre os livros na aba Livros.
  2. Cadastre os alunos na aba Alunos.
  3. Registre empréstimos na aba Empréstimos e marque a devolução quando o livro voltar.
  4. Use Relatórios para consultar e exportar os dados.

Os dados ficam salvos neste navegador e neste dispositivo. Use “Fazer backup” em Relatórios para guardar uma cópia. Não limpe os dados do navegador sem exportar o backup.
